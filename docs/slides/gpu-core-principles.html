GPU core principles · Architecture

CPU minimizes latency. GPU maximizes throughput.

Both are parallel—but a few sophisticated CPU cores finish diverse tasks quickly, while many GPU lanes move far more total work.

GPU core principles · Parallelism

Many threads in flight keep memory and math busy.

The GPU exposes a much larger concurrency window—independent work can fill wide execution and memory pipelines.

GPU core principles · Scheduling

When one warp waits, the GPU issues another.

Resident warp state stays on-chip, so the scheduler can select ready work with very little handoff overhead.

What the scheduler does

1A load or dependency stalls Warp A.
2A’s execution state remains resident on-chip.
3The scheduler selects a ready Warp B, C, or D.
4Warp A resumes when its data is ready.
