# GPU Engineering Starter Resources

A compact technical hub for engineers building, profiling, and optimizing CUDA software.

## Start here

- [NVIDIA Training / Deep Learning Institute (DLI)](https://www.nvidia.com/en-us/training/find-training/?topics=accelerated+computing) — hands-on, GPU-backed CUDA and accelerated-computing courses.
- [CUDA Programming Guide](https://docs.nvidia.com/cuda/cuda-programming-guide/) — the programming model, execution, memory, and advanced CUDA features.
- [NVIDIA Accelerated Computing Hub](https://github.com/NVIDIA/accelerated-computing-hub) — open tutorials and GPU-programming guides.
